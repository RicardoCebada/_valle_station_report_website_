2. Horas de mayor radiación

Los picos máximos de radiación (Visible, Infrarroja y UV) ocurren de forma consistente en la franja vespertina: * Franja horaria: Entre las 17:00 UTC y las 19:00 UTC de cada día. * Ejemplo máximo: El 26 de octubre a las 19:00 UTC se registraron los valores pico de todo el set de datos (radiacion_vis: ~682 W/m², radiacion_ir: ~5642 W/m², radiacion_uv: ~2.27).

3. Falla en sensores

Se detectan anomalías críticas y fallas de lectura en el sensor de humedad (humedad): * Comportamiento anómalo: El sensor arroja frecuentemente valores negativos absurdos (principalmente -999.9, además de -609.5, -311.3, etc.). * Diagnóstico: En instrumentación IoT, un valor fijo como -999.9 es un código estándar de error de hardware (null/timeout/desconexión del ADC o I2C) o saturación extrema fuera de rango del sensor de humedad relativa, lo que indica que el sensor de humedad está averiado o perdiendo calibración. Los sensores de temperatura (temp_sensor1, 2 y 3) y radiación operan con normalidad.
