3. Falla en Sensores (Anomalías Detectadas)

Durante el análisis de telemetría se detectaron fallas críticas de lectura (valores fuera de rango/hard-faults): * Sensor de Humedad: Presenta fallas recurrentes de lectura con valores negativos absurdos (ej. -999.9 y -537.2). Esto indica una desconexión física del sensor, un error de conversión analógica-digital (ADC) o un volcado de búfer por fallo en el bus I2C/SPI del nodo IoT. * Sensores de Temperatura (1, 2 y 3): Aunque operan dentro de rangos lógicos, se observa una deriva térmica constante entre ellos (el Sensor 3 marca consistentemente ~2 °C menos que el Sensor 1), lo que sugiere la necesidad de una recalibración por software o degradación del elemento termistor.
