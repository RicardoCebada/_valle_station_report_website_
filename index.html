Se detectaron anomalías críticas y fallas intermitentes exclusivamente en el sensor de humedad: * Lecturas negativas anómalas: El sensor de humedad presenta caídas abruptas a valores negativos imposibles en la física ambiental (ej. -329.75, -725.25 y hasta -999.9). * Diagnóstico: El valor -999.9 es un código de error estándar de firmware para "Sensor Timeout" o "Circuito Abierto", lo que indica que el transductor de humedad está sufriendo fallas de comunicación I2C/analógica o problemas de alimentación eléctrica intermitente. Los sensores de temperatura (sensor 1, 2 y 3) operan de manera estable y coherente entre sí.
